
# JAVA 계산기 

## 1. Project Overview (프로젝트 개요)
**프로젝트명: Java 계산기** 
<br>✅클래스 활용하여 기능 나누기 
<br>✅메소드 구현하고 호출하여 활용하기

## 2. Project Structure (프로젝트 구조)
```plaintext
Calculator/
├── src/
│   ├── calculator/          
│       ├── App.java          # 입출력 및 Calculator 호출 
│       ├── Calculator.java   # 계산 연산 및 결과값 저장             
```

## 3. Key features (주요 기능)
**사칙연산**
<br>
- 피연산자 2개와 연산자 1개 값을 입력받아 계산합니다.
  - 피연산자 입력시, 양의 정수만 입력이 가능합니다.
  - 연산자 입력시, 사칙연산 기호 외의 입력은 불가합니다.


**오류상황**
<br>
- 나눗셈 시, 분모가 0이면 입력오류 메세지와 함께 계산기의 처음으로 돌아갑니다.
- 연산자 입력시, 문자 혹은 빈칸을 입력하면 오류가 발생합니다.
